## `04` — SECURITY MINDSET

### Security isn't something I bolt on after deployment.

I approach applications with security considerations throughout development — especially around **trust boundaries, authentication, authorization, input handling, data access, sessions, and output**.

| Layer | Focus |
|---|---|
| Input | Validation · Sanitization · Trust boundaries |
| Identity | Authentication · Password security · Sessions |
| Access | Authorization · Privilege boundaries · Access control |
| Data | Secure queries · Safe data handling |
| Output | Encoding · XSS defense |
| Requests | CSRF protection · Request validation |
| Platform | Security headers · Secure configuration |

### Security Areas

`OWASP Top 10` · `Secure Coding` · `Authentication` · `Authorization` · `Access Control` · `XSS` · `SQL Injection` · `CSRF` · `Session Security` · `Security Headers` · `API Security`
